# mods-monorepo
Per-game mod packs, each with its own installer. Layout: `<game>/<pack>/`; third-party zips go in `<game>/<pack>/files` (git-ignored).

| Cyberpunk 2077 | KK-Photorealism: ReShade + KK Photorealism preset (patch 2.5, no ray tracing needed) | [Cyberpunk2077/KK-Photorealism](Cyberpunk2077/KK-Photorealism/) |
